This README explains what the project contains, how it works, and which files to study so you can present it confidently. It reflects the source code, documentation, and Git history available on October 30, 2026, including local changes that have not been committed yet. Earlier conversations outside this session are unavailable. This guide does not attribute all team changes to one person or reproduce the chat history.

1. What is the project?
Rently is a car rental agency management application. Customers can browse vehicles, choose rental dates and extras, and make reservations. Administrators manage vehicles, reservations, users, locations, the catalog, FAQs, notifications, and reports.
